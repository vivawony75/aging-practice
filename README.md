# 🏛️ 국립부경대학교 사회복지학전공 공식 홈페이지
> **PKNU Department of Social Welfare Modern Scrolling Landing Page**  
> 모던 시네마틱 히어로와 **3D 곡면(Curved Arc) 카드 캐러셀**, 부드러운 스크롤 네비게이션으로 새롭게 디자인된 국립부경대학교 사회복지학전공 공식 웹페이지입니다.

---

## 🌟 새로운 디자인 및 주요 특징 (Features)

### 1. 🌄 감각적인 시네마틱 히어로 & 3D 곡면(Curved Arc) 카드
- **볼드 타이포그래피**: 고해상도 자연/캠퍼스 배경 위에 선명한 볼드 타이틀 및 소개 문구 배치
- **알약 형태(Pill-shaped) CTA 버튼**: 부드러운 호버 애니메이션이 적용된 '전공 둘러보기 ↗' 바로가기 버튼
- **3D 곡면 원통형 아크 카드 캐러셀 (Curved Arc 3D Cards)**:
  - 5장의 라운드 카드가 부드러운 3D 원통형 곡면(Curved Arc) 형태로 입체감 있게 배치
  - 마우스 호버 시 카드가 자연스럽게 앞으로 돌출되며 상세 캡션 노출

### 2. 📜 부드러운 스크롤형(Vertical Scroll) 구조 & Scroll-Spy
- 상단 글래스모피즘(Glassmorphism) 고정 네비게이션 바로 스크롤 위치에 맞춰 현재 메뉴 자동 활성화
- 원클릭 탑 스크롤 버튼 제공으로 편리한 페이지 탐색

### 3. 📚 충실하게 수록된 부경대 사회복지학전공 콘텐츠
1. **전공 소개 (Department Overview)**: 교육 비전, 핵심 가치(공감, 실천, 혁신), 복지ICT 마이크로전공, 학과 사무실(인문사회경영관 C25 724호) 및 연락처 안내
2. **학부 및 대학원 구분 (Academic Programs)**:
   - **학부 (사회복지학전공 - 학사)**: 4개 학년별 로드맵, 복지ICT 마이크로전공, 160시간 현장실습, 1급 시험 대비
   - **일반대학원 (석사·박사)**: 전일제 학술 연구자 및 대학교수 양성
   - **글로벌정책대학원 (실무 석사)**: 야간 전문실무 과정, 현장 복지기관장 및 공무원 맞춤형 리더십 과정
   - **3개 과정 종합 비교표**: 학위, 목표, 수업형태, 진로 한눈에 비교
3. **교수진 소개 (Faculty Members)**:
   - **오영삼 교수** [학부 전공주임], **허원빈 교수** [일반대학원 학과주임], **노법래 교수** [글로벌정책대학원 학과주임], **김은정 교수**, **조윤호 교수**
   - *실시간 교수 성함 및 연구분야 키워드 검색창 내장*
4. **다솜모임 (DASOM Gathering)**:
   - 순우리말 '사랑'의 학과 대표 자치 학술·실천 모임
   - 4대 특성: ① 실천적 학술 연구, ② 지역사회 밀착 나눔과 봉사, ③ 선후배 멘토-멘티 결속, ④ 정기 활동보고회
5. **학생활동 & 동아리 (Student Life & Clubs)**:
   - 학생회 사계절 캘린더 (배움터, 하계실습, 사회복지인의 밤, 1급 응원)
   - 전공 동아리: **HORA (오라)**, **클럽신화**, **theme:띰**, 학과 공식 유튜브 채널(`@ps1pknu`)
6. **학과 성과 (Achievements)**:
   - 대연3동 복지공감 네트워크 협약 체결 (2026), 정효택 장학생 배출, Credi-T 비교과 공모전 수상, 미래내일 일경험 공모전 수상, 졸업생 취업 진로 현황
7. **사회복지 정보마당 (Welfare Hub)**:
   - 사회복지사 1급 시험 과목 및 합격 기준(전 과목 총점 60% 이상)
   - 현장실습 160시간 필수 이수 4단계 프로세스
   - 정신건강·의료·학교사회복지사 및 건강가정사 취득 요건
   - 복지로, 한국사회복지사협회, 부산사회복지사협회 등 필수 링크
8. **공식 인스타그램 & 갤러리**:
   - 공식 인스타그램(`@pknu_ps1`) 프로필 연동 및 최신 피드 카드 갤러리

1. 본 폴더(`홈페이지만들이` 또는 `홈페이지만들기`)를 엽니다.
2. `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 웹 브라우저에서 바로 열 수 있습니다.
3. 별도의 설치나 웹서버 없이 **단독 실행(Standalone)**이 가능합니다.

## 🚀 깃허브(GitHub) 업로드 및 GitHub Pages 무료 배포 방법

### 1단계: 깃허브 저장소 생성
1. [GitHub](https://github.com/) 로그인 후 우측 상단의 **[New repository]** 클릭
2. 저장소 이름 입력 (예: `pknu-social-welfare`)
3. **Public** 선택 후 **[Create repository]** 클릭

### 2단계: 폴더에서 Git 명령어 실행
바탕화면의 `홈페이지만들이` 폴더 안에서 터미널(PowerShell 또는 Git Bash)을 열고 실행합니다:

```bash
# 1. git 초기화
git init

# 2. 모든 파일 스테이징
git add .

# 3. 커밋 생성
git commit -m "feat: 국립부경대학교 사회복지학전공 스크롤형 모던 웹사이트 완성"

# 4. 브랜치명을 main으로 설정
git branch -M main

# 5. 본인의 깃허브 저장소 주소 연결
git remote add origin https://github.com/사용자아이디/저장소이름.git

# 6. 깃허브로 푸시
git push -u origin main
```

### 3단계: GitHub Pages 무료 호스팅 활성화
1. 깃허브 저장소 상단 메뉴의 **[Settings]** ➔ 좌측의 **[Pages]** 클릭
2. **Build and deployment > Branch**를 `None` ➔ **`main`** 으로 변경
3. **[Save]** 클릭
4. 약 1분 뒤 페이지 상단에 나타나는 주소(`https://사용자아이디.github.io/저장소이름/`)로 전 세계 누구나 웹페이지에 접속할 수 있습니다!
