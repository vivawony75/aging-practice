# 🏛️ 국립부경대학교 사회복지학전공 웹사이트
> **PKNU Department of Social Welfare Interactive Web OS**  
> Noni Cerâmica 감성의 어시(Earthy) 도자기 컬러 팔레트와 인터랙티브 **윈도우(Window OS) 시스템**으로 제작된 국립부경대학교 사회복지학전공 공식 소개 웹페이지입니다.

---

## 🌟 주요 특징 및 구성 (Features)

### 1. 🪟 감성적인 윈도우 OS 데스크톱 인터페이스
- **창 제어 시스템**: 각 메뉴가 독립된 윈도우 창으로 열리며, 드래그 이동, 최소화(`_`), 최대화/복원(`□`), 닫기(`✕`)를 자유롭게 지원합니다.
- **작업 표시줄 (Taskbar)**:
  - **시작 메뉴**: 부경대 엠블럼과 전공의 모든 창을 한눈에 열 수 있는 시작 메뉴 팝업
  - **실행 탭**: 현재 열려 있는 창들을 작업표시줄에서 클릭하여 포커스 전환 및 최소화
  - **시스템 트레이**: 실시간 한국 표준시 시계/달력, 도자기 톤 팔레트 체인저, 바탕화면 바로보기
- **인터랙티브 사운드**: 도자기를 가볍게 두드리는 듯한 부드럽고 따뜻한 햅틱 톤 사운드(Web Audio API 내장, 음소거 지원).

### 2. 🎨 Noni Cerâmica 모티브의 디자인 시스템
- **Natural Earthy Palette**:
  - `Aveia (Oat/Sand)`: 따뜻하고 부드러운 오트밀 린넨 바탕
  - `Cafecito (Clay)`: 깊이 있는 테라코타 클레이 톤 (주요 버튼 및 헤더)
  - `Blush (Glaze)`: 은은한 장미빛 유약 핑크 (다솜모임, 닫기 버튼, 하이라이트)
  - `Grass (Sage)`: 생기 있는 풀빛 세이지 그린 (최대화, 신입생/학부 배지)
  - `Ink Charcoal`: 눈이 편안한 먹색 타이포그래피
- **수공예 도자기 질감**: 부드러운 곡률(`border-radius: 14~20px`), 은은한 앰비언트 클레이 그림자, 세라믹 핀 메모지.

### 3. 📚 부경대학교 사회복지학전공 완벽 콘텐츠 수록
1. **🏛️ 학과 소개 (win-intro)**: 1998년 설립 이래 28년 전통, 교육목적, 핵심가치, 복지ICT 마이크로전공, 학과 사무실(인문사회경영관 C25 724호) 안내.
2. **🎓 교수진 소개 (win-faculty)**:
   - **김은정 교수** (사회복지정책, 사회복지행정, 지역복지서비스)
   - **오영삼 교수** [학부 전공주임] (사회복지실천, 사회복지실천기술, 노인복지)
   - **허원빈 교수** [일반대학원 학과주임] (사회복지실천, 아동복지, 중독과 정신건강, 질적연구방법)
   - **노법래 교수** [글로벌정책대학원 학과주임] (복지국가 및 지역비교, 사회통계/빅데이터)
   - **조윤호 교수** (아동청소년복지, 국제개발협력, 지역사회개발)
   - *실시간 교수진 성함 및 연구분야 검색 필터 내장*
3. **📚 학부 및 대학원 구분 (win-curriculum)**:
   - **학부 (사회복지학전공)**: 4년 학사과정, 복지ICT 마이크로전공, 160시간 현장실습, 1급 국가시험 로드맵
   - **일반대학원 (석사·박사)**: 주간 전일제 학술 연구자 및 대학교수 양성
   - **글로벌정책대학원 (석사)**: 야간 전문실무 과정, 현장 복지기관장 및 공무원 맞춤형 리더십 과정
   - **종합 비교표**: 3대 과정의 수여학위, 교육목표, 수업방식, 진로를 한눈에 비교
4. **🤍 다솜모임 (win-dasom)**:
   - 순우리말 '사랑'에서 유래한 유서 깊은 학과 대표 자치모임
   - 4대 특성: ① 실천적 학술 연구, ② 지역사회 나눔과 밀착 봉사, ③ 선후배 멘토-멘티 결속, ④ 정기 활동보고회(통합 차수별 운영)
5. **🌱 학생활동 & 동아리 (win-activities)**:
   - 학생회 사계절 캘린더 (신입생 배움터, 실습, 사회복지인의 밤, 1급 응원전)
   - 전공 동아리: **HORA(오라)**, **클럽신화**, **theme:띰**, 학과 공식 유튜브 채널(`@ps1pknu`)
6. **🏆 학과 성과 (win-achievements)**:
   - 대연3동 복지공감 네트워크 협약 체결
   - 2025 Credi-T 학생주도형 비교과 아이디어 공모전 수상
   - 미래내일 일경험 공모전 우수성과 수상, 정효택 장학생 배출
   - 전국 최상위권 1급 합격률 및 졸업생 진로 현황(공무원, 병원, 공단, NGO)
7. **💡 사회복지 정보마당 (win-welfarehub)**:
   - 사회복지사 1급 시험 과목 및 합격기준 완벽 가이드
   - 현장실습 160시간 필수 이수 4단계 프로세스
   - 정신건강·의료·학교사회복지사 및 건강가정사 취득 요건
   - 복지로, 한국사회복지사협회, 부산사회복지사협회 등 유관기관 바로가기
8. **📸 인스타그램 & 갤러리 (win-sns)**:
   - 공식 인스타그램 계정(`@pknu_ps1`) 프로필 연동 및 최신 피드 카드 갤러리

## 💻 로컬에서 실행하는 방법

1. 본 폴더(`홈페이지만들이` 또는 `홈페이지만들기`)를 엽니다.
2. `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 웹 브라우저에서 바로 열 수 있습니다.
3. 별도의 설치나 서버 실행 없이 **단독 실행(Standalone)**이 가능합니다.

## 🚀 깃허브(GitHub)에 업로드 및 무료 호스팅(GitHub Pages) 방법

### 1단계: 깃허브 저장소 생성
1. [GitHub](https://github.com/)에 로그인 후 우측 상단의 **[New repository]**를 클릭합니다.
2. 저장소 이름(Repository name)을 입력합니다. (예: `pknu-social-welfare` 또는 `pknu-welfare-web`)
3. **Public**으로 설정하고 **[Create repository]**를 클릭합니다.

### 2단계: 폴더에서 Git 명령어 실행
바탕화면의 `홈페이지만들이` 폴더 안에서 터미널(PowerShell 또는 Git Bash)을 열고 다음 명령어를 순서대로 입력합니다:

```bash
# 1. git 초기화
git init

# 2. 모든 파일 스테이징
git add .

# 3. 커밋 생성
git commit -m "feat: 국립부경대학교 사회복지학전공 윈도우 스타일 웹사이트 완성"

# 4. 브랜치명을 main으로 설정
git branch -M main

# 5. 본인의 깃허브 저장소 주소 연결 (본인 계정 URL로 변경)
git remote add origin https://github.com/사용자아이디/저장소이름.git

# 6. 깃허브로 푸시
git push -u origin main
```

### 3단계: GitHub Pages 무료 웹사이트 배포 (누구나 접속 가능)
1. 깃허브 저장소 페이지의 상단 메뉴에서 **[Settings]** 탭을 클릭합니다.
2. 좌측 사이드바 메뉴 중 **[Pages]**를 클릭합니다.
3. **Build and deployment > Branch** 섹션에서:
   - Branch: `None` ➔ **`main`** 으로 변경
   - Folder: **`/(root)`** 그대로 유지
4. **[Save]** 버튼을 클릭합니다.
5. 약 1~2분 뒤 페이지 상단에 배포된 홈페이지 주소(`https://사용자아이디.github.io/저장소이름/`)가 나타나며, 전 세계 어디서든 브라우저로 접속할 수 있습니다!
